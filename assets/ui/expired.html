upkeep

This link is from a previous run.

upkeep ui mints a fresh token each time it starts, so a tab left open across a restart — or a bookmark — carries one that no longer works. Nothing is wrong with your cockpit, and there is nothing to repair.

To get a working link

  1. Find the terminal running upkeep ui and use the URL it printed when it started — that token is the only one this server accepts.
  2. If you cannot find it, press Ctrl+C in that terminal to stop it, then run upkeep ui again and follow the new URL.

There is no way to re-print the current link: the token is held only in the running process and never written to disk. Restarting is the way to get a new one.
